# IMDB Movie Review Sentiment Analysis

This project focuses on developing a sentiment analysis system to classify IMDB movie reviews as either positive or negative using Natural Language Processing (NLP) techniques and machine learning models.

The workflow includes text preprocessing, feature extraction, and model training. Multiple machine learning algorithms were implemented and compared, including Support Vector Machine (SVM), Logistic Regression, and Naive Bayes. Model performance was evaluated using standard classification metrics to identify the most effective approach.

---

## Project Workflow

- Data loading and text preprocessing  
- Tokenization, stopword removal, and feature extraction  
- Model training using different machine learning algorithms  
- Model comparison and evaluation using performance metrics  

---

## Models Used

- Support Vector Machine (SVM)  
- Logistic Regression  
- Naive Bayes  

---

## Technologies Used

- Python  
- Pandas, NumPy  
- Scikit-learn  
- Natural Language Processing (NLP) techniques  

---

## Objective

The objective of this project is to build an effective sentiment classification system for movie reviews and gain hands-on experience with NLP workflows and machine learning model comparison.

---

## Conclusion

This project provided practical experience in text preprocessing, feature engineering, and evaluating multiple machine learning models for sentiment analysis tasks.
